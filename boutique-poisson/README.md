# Ma Poissonnerie : gestion de boutique

Application web (ordinateur et mobile) pour gérer une boutique de produits halieutiques et de produits divers : achats, ventes du jour, stock, dépenses, pertes, bénéfices. Les données sont stockées dans un Google Sheet.

- `apps-script/` : application (serveur Google Apps Script + interface `Index.html`)
- `demo/index.html` : démonstration autonome (données locales au navigateur)
- `tools/` : tests Node et générateur de la démo
- `docs/INSTALLATION.md` : mise en ligne pas à pas, méthode de calcul, utilisation

Cette application est indépendante de l'application AgroScan présente à la racine du dépôt.
